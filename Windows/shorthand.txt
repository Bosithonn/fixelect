# Expanded before the model ever sees your text. Format: shorthand=expansion
# One per line, case-insensitive, # for comments. Capitalisation is preserved,
# so "Thx" becomes "Thanks".
#
# Why this file exists, and why it is not the model's job:
#
#   - The model's candidates only stretch about one edit, so "abt" can never
#     reach "about" and "u" can never reach "you". They are not misspellings
#     anyway - they are deliberate abbreviations.
#   - Left alone the model expands contractions the wrong way: "im" becomes
#     "I am" rather than "I'm", which then wrecks the word alignment and the
#     guard throws the whole sentence away.
#
# A table has no opinion, so it cannot get either of these wrong.
#
# "its" is deliberately absent: "its colour" and "it's cold" are both correct
# English and only context separates them. That one stays the model's problem.
