### What's new in 1.3.0
- **See what changed.** After a fix, the card lists the corrected words, like *teh → the · beleive → believe · +2 more*.
- **Fix without selecting.** Nothing selected? The shortcut fixes the line you're typing, from its start to the cursor. Turn it off in Settings → Writing.
- **History.** Settings → History lists your last 30 changes with **Copy original** and **Copy result**, so a bad fix can be recovered after Undo is gone. It's kept only on your computer. Turn it off or clear it there.

### Fixes
- A cancelled or broken update download no longer leaves a half-written installer behind.
- The DeepSeek R1 model is no longer offered. It thinks out loud before answering, which made fixes slow. If you used it, Fixelect switches you to Qwen 2.5 1.5B, which is the same size.
- Model downloads now use the same code on Windows and macOS, with new tests for resuming, cancelling and checksum checks.
