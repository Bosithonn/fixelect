### What's new in 1.2.0
- **Quick actions.** Select text and press **Ctrl + Alt + Space** (Windows) or **⌃ ⌥ Space** (Mac) for a menu at your text: Fix, Polish, Polish in another style, **Translate**, and **your own actions**. Press a number to choose, or use the arrow keys and Enter.
- **Translate** into English, Spanish, French, German, Portuguese, Italian, Russian or Ukrainian (plus Uzbek with the Gemma 4 model), right where you type. Long text is translated piece by piece; Esc cancels. Like everything in Fixelect, it runs offline.
- **Your own actions.** Two examples to start ("Bullet points" and "Summarize"); add your own under Settings → **Actions**, like "Reply politely" or "Make it sound like me". Each one gets a number in the menu.
- Every release is now tested end to end on **Windows** too: installed from the real installer, then Fix, Polish, Translate and a custom action in Notepad.
