### What's new in 1.1.4
- **Your clipboard is never pasted by mistake.** Fixelect now waits longer before putting back what you had copied, so slow apps (Word, Slack, a busy computer) always paste the fixed text.
- **No duplicated lines in code editors.** With nothing selected, VS Code and Cursor copy the whole line; Fixelect now recognises that and asks you to select text instead of pasting the line twice.
- **Mac: a guided first launch.** After you allow Accessibility, the Welcome tour opens so you learn the shortcuts right away.
- **Mac: "Move to Applications".** Opened straight from the disk image, Fixelect offers to move itself, so it keeps working after you eject the disk and can start at login.
- **Mac: starts even when the GPU hangs.** If the graphics chip doesn't respond, the model loads on the processor instead of failing.
- **Windows: reliable double-tap on a busy PC.** Taps are timed by when you pressed the keys, as on the Mac.
- **Windows: smoother in-app updates.** Fixelect steps aside before the installer starts, so it can replace every file.
