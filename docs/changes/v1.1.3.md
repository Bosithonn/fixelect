### What's new in 1.1.3
- **Mac: the double-tap works.** Fixelect now listens for shortcuts itself and needs only the Accessibility permission. Before, it silently waited for a second permission (Input Monitoring) that it never asked for.
- **Mac: the double-tap is reliable on a busy Mac.** Taps are timed by when you pressed the keys, not by when Fixelect got to them, so a double-tap made while the model loads still counts.
- **Mac: Polish is now double-tap Shift (⇧ ⇧).** Double-tap Control is macOS's Dictation shortcut, so it opened Dictation instead. Fix stays double-tap Option (⌥ ⌥).
- **Mac: the Polish preview answers the keyboard.** Return replaces, Esc cancels and R tries again, even while your app stays in front. Before, Return went into your document.
- **Mac: easier permission step.** Fixelect appears in the Accessibility list by itself, so you only flip its switch.
- **Mac: works without the GPU.** If Metal can't start, the model runs on the processor.
- Every release is now tested on macOS 26 and macOS 15: Fixelect is installed from the disk image and fixes and polishes real text in TextEdit.
